# 登录与权限开发说明

## 登录链路

管理端在没有会话时只显示登录页。登录必须依次完成：

1. 创建两分钟有效的一次性滑块挑战；
2. 前端使用与酒店项目相同的 `vue3-slide-verify` Canvas 拼图组件采集滑动结果；
3. 使用租户、用户名、密码、挑战 ID 和滑块位置发起登录，服务端同时完成最终校验；
4. 服务端签发带 `sub`、`tenant_id`、`roles`、`jti` 和过期时间的 JWT；
5. 每次受保护请求同时验证 JWT 签名与数据库会话，退出、停用账号、修改密码或角色都会使相关旧会话失效。

密码使用 Argon2 哈希保存。连续五次密码错误会锁定账号 15 分钟。浏览器只在当前标签页的 `sessionStorage` 保存会话，关闭标签页后不会长期保留。

## 默认角色权限

| 角色 | 权限 |
| --- | --- |
| `operator` | 仪表盘读取、任务读取、创建、取消 |
| `approver` | 仪表盘读取、任务读取、审批决策 |
| `admin` | 上述全部权限、用户读取与用户维护 |

权限在后端 API 依赖层强制校验，前端菜单隐藏仅用于改善体验，不能代替服务端授权。租户和用户身份只从已签名会话生成，客户端请求体中的同名字段不会覆盖登录身份。

## 本地开发账号

- 租户：`local`
- 用户名：`admin`
- 密码：`Admin@123456`

可通过 `BOOTSTRAP_ADMIN_TENANT`、`BOOTSTRAP_ADMIN_USERNAME` 和 `BOOTSTRAP_ADMIN_PASSWORD` 修改首次启动账号。已有管理员时不会覆盖密码。生产环境会拒绝默认密码、开发密钥以及自动建表配置。

## 生产接入边界

当前滑块实现与酒店项目保持一致，用于本地开发和业务框架验收，具备 Canvas 拼图交互、服务端时效校验和一次性消费，但不等同于专业反自动化服务。正式公网部署应在相同 API 边界替换为企业验证码或风控供应商，并增加 IP、设备和账号维度限流。

如企业统一身份平台已经提供 OIDC/JWT，可设置 `AUTH_MODE=jwt` 并配置发行方、受众与受管密钥；此模式验证外部令牌，不要求本地会话记录。生产建议进一步升级为 OIDC Discovery + JWKS 非对称签名和密钥轮换。
